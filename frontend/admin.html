📧 Gmail API Settings (Outgoing Email) Not Configured
📋 How to set up Gmail API:
1. Go to Google Cloud Console → APIs & Services → Enable Gmail API
2. Go to Credentials → Create an OAuth 2.0 Client ID (Desktop app type)
3. Add https://www.googleapis.com/auth/gmail.send scope to your OAuth consent screen
4. Complete a one-time OAuth flow to get a refresh token
5. These credentials are independent from Google Calendar — you can use different Google accounts for each.

📥 Gmail API Settings (Incoming Leads) Not Configured
📋 How this works:
The system will check this mailbox every few minutes for emails with "Website Lead" in the subject.
It will extract lead info and automatically assign it to your salespersons in a round-robin format.
Important: You must create an OAuth 2.0 Client ID and authorize it to get a refresh token with `gmail.readonly` and `gmail.modify` scopes for the receiving email address.

📅 Google Calendar Settings Not Configured
📋 How to get credentials:
1. Go to Google Cloud Console → APIs & Services → Credentials
2. Create an OAuth 2.0 Client ID (Desktop app type)
3. Enable Google Calendar API in your project
4. Use the client ID & secret to complete a one-time OAuth flow to get a refresh token
5. The admin calendar email is the Google account whose calendar will be used for meetings.
🕐 Office Hours & Meeting Settings
📋 How this works:
Set the working hours for meeting scheduling. All users (admin, salespersons) and clients (booking page) can only schedule meetings within these hours (IST).
The buffer ensures a gap between consecutive meetings for the same person. E.g., a 30-minute buffer means if a meeting ends at 4:00 PM, the next meeting can only start at 4:30 PM.
